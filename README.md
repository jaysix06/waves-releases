# Waves downloads

Waves is a private band song bank and setlist app for Android.

Download Waves at https://waves-abc5e.web.app/download.

This repository contains public APK releases only. The app's source code is not published here.

Install a new APK over your existing Waves app. Do not uninstall Waves first, so your login, local songs, lyrics, and pending edits remain on your phone. Android asks you to approve the installation.

Each release includes a SHA-256 checksum. Official Waves APKs use package `app.waves.band` and this signing certificate SHA-256:

`156893140a81870907b38fe2322cda3c7ea5579f2f204ddbdc438f83cf68f07b`

You do not need a GitHub account to download an APK. The Waves website remains the band-facing download link.
